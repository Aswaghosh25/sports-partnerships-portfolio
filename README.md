# Aswaghosh S. Portfolio

GitHub Pages-ready portfolio. All project files are placed in the repository root (no folders required).

## Files
- `index.html` — website entry point
- `style.css` — styles and embedded visual assets
- `main.js` — interactions
- `Aswaghosh-S-Resume.pdf` — downloadable resume

For GitHub Pages, upload these files to the root of your repository and enable Pages from Settings → Pages.
