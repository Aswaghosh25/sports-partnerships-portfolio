# Sports Partnerships Portfolio

A responsive, single-page portfolio website for Aswaghosh S.

## Files
- `index.html` — page structure and embedded images
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, scroll progress and footer year

## Deployment
Upload these three files to the root of your GitHub repository. No assets folder is required because the supplied portrait and project photographs are embedded directly in `index.html`.

The site uses Google Fonts (DM Sans and Space Grotesk); the browser needs an internet connection to load them. All photographs are embedded locally in the HTML.

## Content notes
- Fan90 metrics: 200+ accounts managed, 79+ acquired/onboarded, $1.5M+ pipeline.
- Manjappada figures are identified as historical/approximate where relevant. Ticketing revenue is described as revenue through operations supported, not solely individual revenue generation.
- Web Curve and IBS Software do not display unverified numerical achievements.
