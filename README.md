# Sports Partnerships Portfolio

Static portfolio website for GitHub Pages / Vercel. The portrait and supplied project visuals are embedded directly in `index.html`, so no assets folder is required.

## Deploy with browser-based GitHub
1. Open your `sports-partnerships-portfolio` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` from this folder.
4. Commit the changes to `main`.
5. Vercel will redeploy from the connected repository.

Before publishing, replace the placeholder email and LinkedIn URL, and verify all dates, role descriptions and metrics.
