# Sports Partnerships Portfolio

Responsive single-page portfolio for Aswaghosh S.

## Files
- `index.html` — page structure and embedded images
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, scroll progress and footer year

## Deploy
Upload the three site files to the root of the GitHub repository connected to Vercel, then redeploy. No assets folder is required; the portrait and project visuals are embedded in the HTML.

## Latest design changes

- Reworked the Fan90 selected-work tile with a tighter crop of its quiz/poll experience, removing phone status and navigation bars from the visible crop.
