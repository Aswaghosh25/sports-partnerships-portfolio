# Sports Partnerships Portfolio

A responsive personal portfolio focused on sports partnerships, marketing, communications and fan engagement.

## Deploy
This is a static website. Upload `index.html`, `styles.css`, `script.js`, and this README to the root of the GitHub repository connected to Vercel. Vercel will deploy automatically.

## Before publishing
- Replace `hello@example.com` with your professional email address.
- Replace the LinkedIn placeholder with your actual profile URL.
- Review all dates, role descriptions and metrics.
- Replace or supplement the sample photography with your own approved project photographs and campaign assets.
- Confirm that all historical audience and commercial metrics are appropriate to publish.
